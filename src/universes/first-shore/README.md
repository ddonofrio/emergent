# First Shore

Object capabilities and crafting recipes live in `crafting.ts`. The engine handles reach, inventory exchanges and action validation; the agent tools project the universe's definitions into local capabilities. Add recipes using the existing surface experiments or ingredient combinations there. A genuinely new physical interaction still needs a shared engine operation; a new visual shape needs rendering support.

An item's first hold records `item-uses:<kind>` once in durable Learned Knowledge, including every named experiment point and required orientation. This reveals methods and prerequisites, never experiment products. A successful experiment separately records its exact learned recipe. Stored items retain their conditional capabilities, even when no compatible target is nearby. The observer shows all discoveries; inference receives only relevant learned facts. `recall` searches the agent's permanent discoveries, including methods for objects it no longer owns, without exposing untried results.

Goals, next steps, expected observations and reconsideration conditions belong to the agent. Recipes and capability descriptions must not assign objectives or disclose hidden world locations.
